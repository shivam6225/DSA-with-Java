## 🛠️ How to Compile & Run

### Prerequisites
Make sure you have Java Development Kit (JDK 17 or higher recommended) installed:

```bash
java -version
javac -version
```

### Compiling and Running a Solution

```bash
# Navigate to the specific topic folder
cd 01-basics/

# Compile the Java file
javac Solution.java

# Run the compiled class
java Solution
```
